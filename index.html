04 / Playback settings

Repetition & timers

Set repetitions to 0 for continuous repeat until stopped. Set total playback limit to 0 for no time limit. The total playback timer starts after the initial delay.

Example: choose a recording, set a 60-second start delay, 20 repetitions, a 10-second gap, and a 30-minute playback limit.

06 / Storage & reliability

Recordings are stored in IndexedDB on this device and browser. They are not uploaded to GitHub. Use the Save button beside a recording to download a backup. Clearing browser site data can erase the library.

Keep this page open during playback. Android may pause audio or suspend timers when the browser is backgrounded, the screen locks, or battery management intervenes. Screen-wake support is requested when available, but cannot guarantee uninterrupted background playback.
